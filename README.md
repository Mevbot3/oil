# OIL ($OIL)

A meme coin named oil. The ticker is the joke. The peg is Big Oil.

$OIL is a weighted slice of six oil-major stocks:

```
OIL = (0.24 XOM + 0.20 CVX + 0.16 COP + 0.16 SHEL + 0.12 BP + 0.12 OXY) / 69
```

If Exxon pumps, $OIL pumps. If Exxon dumps, we post through it. WTI is just the weather.

## Run it

```bash
npm install
npm run dev
```

Open [http://127.0.0.1:43147](http://127.0.0.1:43147).

The tape is pulled from Yahoo Finance. If the quote feed is down, the last known field prices still run the desk.
